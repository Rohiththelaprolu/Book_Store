# 📚 BookHive - Online Bookstore

A modern, responsive Indian online bookstore built with HTML5, CSS3 and JavaScript.

## Features
- 8 connected pages
- Dynamic book catalog with 14 books
- Search, category filtering and sorting
- Individual book detail page
- Shopping cart with quantity controls and `localStorage`
- Login, signup and contact forms with HTML5/JavaScript validation
- Responsive Flexbox and CSS Grid layouts
- Lazy-loaded book cover images
- SEO meta tags, Open Graph metadata and accessibility labels
- Indian pricing in ₹ and Indian context

## Built With
- HTML5 semantic markup
- CSS3 variables, Flexbox, Grid, media queries and animations
- JavaScript ES6+, DOM manipulation, map/filter/reduce/find/sort
- Browser `localStorage`

## Run
Open `index.html` with VS Code Live Server.
